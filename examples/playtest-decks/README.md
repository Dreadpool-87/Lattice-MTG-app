# Playtest example decks

Choose **Decks → Import → Choose a Playtest example**, pick a deck, and confirm **Import**. Then open the imported deck and choose **Playtest**. On an earlier app version, paste the text file into the deck import dialog, keep the section headers, and choose the format from the table. Import while online so Lattice can resolve cards missing from its local catalog.
